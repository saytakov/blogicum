Социальная сеть блогикум

В данном сайте релизовано действия с постами, как в социальной сети
Написание, удаление, редактирование постов
Реализованы личные аккаунты пользователей
Реализовано ограничение доступа к написанию, удалению, редактированию постов.

Проект реализован с помощью Django
Запросы к бд написаны на Django ORM
Использоваль SQLite
Подключен Django Debug Toolbar для отладки сайта
Для сайта использовались шаблоны bootstrap

Для запуска проекта потребуется установить библиотеки из requirements.txt

pip install -r requirements.txt

Применить миграции

/blogicum python manage.py migrate

Запустить сервер

/blogicum python manage.py runserver
