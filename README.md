# Блогикум (Blogicum)

## Краткое описание

**Блогикум** — это веб-приложение для ведения блогов, созданное на Django. Платформа позволяет пользователям регистрироваться, создавать, редактировать и удалять посты, оставлять комментарии, а также управлять публикациями (отложенные посты, снятие с публикации). Проект включает систему аутентификации, пагинацию, поддержку изображений для постов и раздельные страницы категорий и профилей пользователей.

**Стек технологий**:
- **Django** (5.1.1) — основной веб-фреймворк.
- **Django ORM** — обращение к БД.
- **SQLite** — база данных (по умолчанию).
- **django-bootstrap5** — стилизация форм и интерфейса.
- **django-debug-toolbar** — отладка (в режиме разработки).
- **Pillow** — работа с изображениями.
- **pytest + pytest-django** — тестирование.

## Установка

1. Клонирование репозитория

```bash
git clone https://github.com/saytakov/blogicum.git
```

2. Установка необходимых библиотек

```bash
pip install -r requirements.txt
```

3. Применение миграций

```
cd blogicum/
python manage.py migrate
```

4. Запуск сервера
```
python manage.py runserver
```

## API

Проект реализует классическую клиент-серверную архитектуру с рендерингом HTML на стороне сервера. Публичного REST API нет, однако можно выделить следующие URL-эндпоинты (все маршруты определены в `blog/urls.py` и `pages/urls.py`):

### Блог (приложение `blog`)

| Метод | Путь | Назначение | Входные параметры | Результат |
|-------|------|------------|-------------------|-----------|
| GET | `/` | Главная страница (лента постов) | `page` (опционально, для пагинации) | HTML со списком опубликованных постов |
| GET | `/posts/create/` | Страница создания нового поста | — | HTML-форма |
| POST | `/posts/create/` | Отправка формы создания поста | `title`, `text`, `pub_date`, `image`, `location`, `category` | Редирект на профиль автора |
| GET | `/posts/<int:post_id>/` | Просмотр отдельного поста | `post_id` | HTML с постом и комментариями |
| GET | `/posts/<int:post_id>/edit/` | Страница редактирования поста | `post_id` | HTML-форма, предзаполненная данными |
| POST | `/posts/<int:post_id>/edit/` | Отправка формы редактирования | `title`, `text`, `pub_date`, `image`, `location`, `category` | Редирект на страницу поста |
| POST | `/posts/<int:post_id>/delete/` | Удаление поста | — | Редирект на профиль автора |
| POST | `/posts/<int:post_id>/create/` | Добавление комментария | `text` | Редирект на страницу поста |
| GET | `/posts/<int:post_id>/edit_comment/<int:comment_id>/` | Страница редактирования комментария | `post_id`, `comment_id` | HTML-форма |
| POST | `/posts/<int:post_id>/edit_comment/<int:comment_id>/` | Отправка отредактированного комментария | `text` | Редирект на страницу поста |
| POST | `/posts/<int:post_id>/delete_comment/<int:comment_id>/` | Удаление комментария | — | Редирект на страницу поста |
| GET | `/category/<slug:category_slug>/` | Страница категории | `category_slug` | HTML со списком постов категории |
| GET | `/profile/<slug:username>/` | Профиль пользователя | `username` | HTML с информацией о пользователе и его постами |
| GET | `/profile/edit/` | Редактирование профиля (только для владельца) | — | HTML-форма |
| POST | `/profile/edit/` | Отправка формы редактирования профиля | `first_name`, `last_name`, `username`, `email` | Редирект на профиль |

### Пользовательская аутентификация (встроенная в Django)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/auth/login/` | Страница входа |
| POST | `/auth/login/` | Аутентификация |
| GET | `/auth/logout/` | Выход (POST) |
| GET | `/auth/password_change/` | Смена пароля |
| GET | `/auth/registration/` | Регистрация (кастомная страница) |

### Статические страницы (приложение `pages`)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/pages/about/` | Страница «О проекте» |
| GET | `/pages/rules/` | Страница «Правила» |

## Запуск тестов

В проекте используется **pytest** с плагином `pytest-django`. Все тесты расположены в директории `tests/`. Файл `pytest.ini` уже настроен.

Для запуска всех тестов выполните команду из корня проекта (в виртуальном окружении):

``` bash
pytest
```


Для запуска конкретного тестового файла:

```bash
pytest tests/test_comment.py
```

Если тесты отсутствуют в вашей сборке — добавьте их самостоятельно.

## Примечания / особенности

- **Отложенные публикации**: посты с `pub_date` в будущем видны только автору.
- **Модерация**: администратор может снять пост или категорию с публикации (флаг `is_published=False`), тогда они становятся скрытыми для обычных пользователей.
- **Изображения**: загружаются в директорию `media/post_images/` (настройка `MEDIA_ROOT`).
- **Права доступа**: редактирование/удаление постов и комментариев доступно только их автору (или администратору).
- **Пагинация**: на всех страницах со списками постов используется пагинация (по 10 записей на страницу).
- **Обработка ошибок**: кастомные страницы для 403, 404 и 500 (шаблоны в `templates/pages/`).
- **CSRF**: для страницы 403 используется отдельный шаблон `403csrf.html`.
