# Blogicum

Blogicum — это платформа для ведения блогов, где пользователи могут создавать, редактировать и удалять публикации, а также оставлять комментарии. Проект реализован на Django с использованием PostgreSQL в качестве базы данных.

**Стек технологий:**
- **Python** 3.10+
- **Django** 5.1.1
- **PostgreSQL**
- **Bootstrap 5** (через `django-bootstrap5`)
- **Pillow** (для работы с изображениями)
- **pytest** и **pytest-django** (тестирование)

## Установка в ручную

```bash
git clone https://github.com/saytakov/blogicum.git
```

2. Установка необходимых библиотек

```bash
pip install -r requirements.txt
```

3. Добавить `.env` в корень проекта с перменными окружения:
- `DJANGO_SECRET_KEY` — секретный ключ Django.
- `BASE_NAME` — имя базы данных PostgreSQL.
- `BASE_USER` — пользователь PostgreSQL.
- `BASE_PASSWORD` — пароль пользователя PostgreSQL.
- `BASE_HOST` — хост базы данных.
- `PORT` — порт PostgreSQL.

4. Применение миграций

```
cd blogicum/
python manage.py migrate
```

5. Запуск сервера
```
python manage.py runserver
```

## Поднятие с помощью Docker Compose

```bash
docker compose up --build
```

## API

Публичного API нет. Проект представляет собой классическое Django-приложение с HTML-шаблонами и взаимодействием через HTTP-запросы.

**Основные маршруты (URL):**

| Раздел | URL | Метод | Описание |
|--------|-----|-------|----------|
| Главная страница | `/` | GET | Список опубликованных постов. |
| Страница категории | `/category/<slug:category_slug>/` | GET | Посты выбранной категории. |
| Профиль пользователя | `/profile/<slug:username>/` | GET | Информация о пользователе и его посты. |
| Редактирование профиля | `/profile/edit/` | GET, POST | Форма для изменения данных профиля. |
| Создание поста | `/posts/create/` | GET, POST | Создание новой публикации. |
| Просмотр поста | `/posts/<int:post_id>/` | GET | Детальная страница поста и комментарии. |
| Редактирование поста | `/posts/<int:post_id>/edit/` | GET, POST | Редактирование существующего поста. |
| Удаление поста | `/posts/<int:post_id>/delete/` | GET, POST | Удаление поста. |
| Добавление комментария | `/posts/<int:post_id>/create/` | POST | Создание комментария к посту. |
| Редактирование комментария | `/posts/<int:post_id>/edit_comment/<int:comment_id>/` | GET, POST | Редактирование комментария. |
| Удаление комментария | `/posts/<int:post_id>/delete_comment/<int:comment_id>/` | GET, POST | Удаление комментария. |
| Аутентификация | `/auth/` | - | Маршруты входа/выхода, смены пароля. |



## Запуск тестов

Для запуска тестов используется `pytest` с настроенным плагином `pytest-django`.

```bash
pytest
```

Тесты проверяют:
- Модели, формы и представления приложений `blog` и `pages`.
- Права доступа и валидацию данных.
- Отображение контента и пагинацию.
- Кастомные страницы ошибок (403, 404, 500).

## Примечания / особенности

- **Отложенные публикации:** Пост с датой публикации в будущем отображается только автору и не появляется в публичных списках.
- **Права доступа:** Редактирование и удаление постов/комментариев доступно только автору или администратору.
- **Изображения:** Посты могут содержать изображения, которые загружаются в директорию `media/post_images/`.
- **Пагинация:** Все списки постов (главная, категория, профиль) разбиты на страницы по 10 записей.
- **Комментарии:** Сортировка комментариев на странице поста — от старых к новым. Автор видит свои скрытые комментарии.
- **E-mail:** Для отправки писем (сброс пароля) используется файловый бэкенд, письма сохраняются в `sent_emails/`.
